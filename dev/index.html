AdaptiveCrossApproximation

This package provides implementations of adaptive cross approximation and several of its variants [1, 3, 6]. It supports different pivoting strategies and convergence criteria [2, 4, 5]. The package also contains the incomplete adaptive cross approximation for efficient pivot selection in the construction of $\mathcal{H}^2$-matrices [7].

Installation

Installing AdaptiveCrossApproximation is done by entering the package manager (enter ] at the julia REPL) and issuing:

pkg> add https://github.com/JoshuaTetzner/AdaptiveCrossApproximation.jl.git
